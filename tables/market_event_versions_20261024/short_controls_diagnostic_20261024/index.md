# 短窗事件研究：三项控制逐项诊断

仅诊断原报告短窗 interaction，不改报告主结果；估计与标准误均由 Stata 生成。

Y 为原始收盘价的对数（沿用 float 精度）；[-5,+5]，-1 为基期。财年2001—2024；surprise沿用 float 工作变量，>0.10为好消息，[-0.10,0.10]为中性；仅纳入完整11日的公告，再按原固定效应删除单例。

受限共同方程：$\log P_{i\tau}=\alpha_{i\times f}+\lambda_k+\delta_\tau+\sum_g\sum_{k\ne-1}\beta_{gk}1\{G_i=g\}Good_{if}D_k+\sum_{k\ne-1}D_k(\gamma_k^{\prime}X_{if}+\kappa_k^{\prime}M_{if})+\varepsilon_{i\tau}$。

固定效应为公司×财年、事件日、实际交易日期；按公司×财年聚类。没有额外增加审计组×事件日。图中同类比较为各组 β 的差；二组模型提供四大−非四大，三组模型提供四大−Other及八大−Other。

规模=财年末总市值对数；MB=财年末价格/每股账面价值；覆盖=ln(1+公告前180天预测券商数)。沿用已生成的按财年中位数填补值及原缺失指示项；每项及其缺失指示都与事件日交互。8个组合逐行核对 e(sample) 完全一致。

读表：系数与标准误均乘100，是对数价格单位的100倍（小幅变化时约为百分比）。p值未作多重检验调整。“单独加入”与“在另两项基础上加入”回答不同问题，相关控制的解释不能简单相加，更不能据此认定中介机制。

与公告日及+5日逐项回归的对应：规模项是四大差异缩小的主要来源。覆盖单独加入也使系数降低，但在规模和MB已加入后独立变化很小；全样本ln市值与ln(1+预测覆盖)的相关系数为0.493。MB单独加入没有压低四大系数。2012年前三项控制均无缺失，因此早期结果变化不可能由中位数填补或缺失指示项造成。全样本只有3份公告的规模和MB同时缺失（同一批本土八大公告），不是大面积填补。

MB有6个负值，最小-116.83、最大244.63，99%分位数15.76；本次保留原值，不缩尾。逐项结果不支持MB是主要系数变化来源，但没有单独识别极端值的影响。

分布及逐项回归支持“组间规模构成及规模相关事件路径影响结果”的解释；不能据此断言规模是混杂因素而非四大作用渠道，也不能从组别均值差直接分配系数变化。各控制的边际影响不能简单相加。

与原受限interaction的联系：原方程没有独立的审计组×事件日项；扣除固定效应后，中性消息客户没有额外的审计组事件路径。新增规模×事件日后，模型可以用规模差异解释中性消息客户的不同路径。四大与非四大的规模差距同时存在于好消息和中性消息内部。它并不等同于直接加入审计组×事件日；给定相同控制值及固定效应时，中性组仍没有额外的审计组事件路径。
