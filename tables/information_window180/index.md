# 共同信息模型：公告前后180天（2026-10-24）

窗口为自然日[-180,-1]与[1,180]，排除公告当天，边界日纳入；仍以DeclareDate、同一券商、同一t+1目标EPS选两侧最近预测。先限制券商配对，再重算n、均值、样本方差和三个Y；没有仅按事件日期删除整行。最近日冲突不回退，A沿用补全基本EPS，n>=2、A>0、有限值及h前后非负条件不变。无缩尾、EPS金额门槛或新闻符号筛选。

180天不保证排除半年报、季报或其他公告。它限制预测距离，不能把窗口内全部信息变化归于年报。

## 完整运行与核查

沿用上一轮12组程序全部重估，主表、控制逐项、市值前25%/50%、排序、分期、FE、覆盖门槛和历史双向聚类规格均保存。共3,759次回归尝试，其中3,435次返回估计、324次观测不足；另有365条对照或联合检验无法推断，详见诊断CSV。观测不足均发生在零覆盖组或2012年前N180为1—2的公司/财年FE分组，没有放宽估计条件。共同事件比较另运行96个主表回归。144个主表回归均核对实际公司年名单，并用Python独立核对系数、公司聚类SE与p值。

`own_sample_comparison.csv`为两窗口各自样本比较；`common_sample_comparison.csv`为固定共同事件比较；`window_event_membership.csv`给出逐事件名单；`news_sign_counts.csv`核对好坏消息覆盖。无限窗口输入及结果哈希不变。

复现：从项目根目录运行`python code/python/information_window180.py build`，再将build换成run执行Stata，最后换成summarize核查。Stata需加入PATH或设置STATA_EXE。新数据在`data/intermediate/market_information/information_window180_20261024/`，do-file在`code/stata/60_market_information/window180_20261024/`，日志在`results/logs/information_window180_20261024/`。

EPS尚为基本EPS参照，所有原始研报口径尚未逐份统一。本轮不改变EPS定义。
