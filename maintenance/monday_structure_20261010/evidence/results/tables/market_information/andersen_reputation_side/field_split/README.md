# 安达信境内、境外字段分别检验

用户确认：用境内及境外审计事务所两个字段分别识别安达信；双重客户进入两次检验。
境外检验沿用原对照组及原境内四大/其他分类，不仅限有境外审计报告的客户。
每次保留对应字段的安达信客户，及境内境外均非安达信的客户；仅另一字段的安达信客户不进入该次对照。

窗口：2001年11月9、12、13日；2002年1月11、14、15日，均中国[0,+2]。
使用2001财年末批客户，三组两个dummy、行业FE、HC1、不缩尾；1月剔除江西铜业600362。
Stata四个模型已执行，八项对比系数与标准误独立OLS核对通过；境内结果与此前输出完全一致。
