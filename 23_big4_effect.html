四大事务所效应

概述

本章围绕一个问题组织两套结果：四大客户的审计失败更少，市场是否也对其盈利消息赋予更高权重？客户质量差异可以来自事前选择和审计服务；市场反应差异还可能来自盈利消息本身的经济内容。我们依次用可观察特征调整、年度客户匹配、换所与匹配 DID，以及门槛和连续盈余消息模型检验这些关系。

核心结果

审计结果的优势在客户层面较明确，换所改善取决于失败定义和比较设计；市场反应在部分正式规格中为正，但其持续时间、大小和精度随估计对象变化。 因此，本章保留审计服务作用与客户选择两种解释，不把控制后剩余差异直接称为不可观察选择或私人信息认证。

  • 可观察选择： 进入四大前三年，未来四大客户已有较大规模、较低亏损和违规发生率；临近进入时，重述没有同步改善。年度 PSM 的五项及九项选择模型均得到较低的三项未预警失败，但仍有尾部不平衡。
  • 换所结果： 九项匹配 DID 的中间口径综合失败和重述分别下降 11.85 和 9.11 个百分点，在逐批次剔除中方向及95%区间稳定。严格综合失败下降5.28个百分点，但对2017批次较敏感；严格重述、违规和宽口径结果保留非显著区间。
  • 市场消息： 连续线性 CAR 模型中，surprise 每增加10个百分点，四大相对 Other 的公告日额外反应为0.0084个百分点；固定 surprise=0.10 时的组间水平差为0.1868个百分点。两者均有正式检验，但不是同一估计量。门槛、共同支持筛选和非线性水平差分别报告。

1. 文献中现有数据可行的基础做法

基础路线是先比较结果，再调整可观察客户特征，随后用同一公司的换所变化检验增量作用，并以连续盈余消息与审计师身份的交互项衡量市场反应。客户匹配的方法参照 Alastair Lawrence、Miguel Minutti-Meza 与 Ping Zhang（2011） 的客户特征框架及 Mark DeFond、David H. Erkens 与 Jieying Zhang（2017） 的匹配设计比较；市场部分对应 Siew Hong Teoh 与 T. J. Wong（1993） 的连续盈余消息反应问题。这里采用本项目既有数据和规格，不声称完全复现其国家、样本及变量。

已完成的基础比较包括共同样本嵌套控制、年度客户 PSM、换所 DID、九项 PSM-DID、动态与批次支持诊断，以及门槛、连续线性和样条市场模型。年度客户匹配与换所匹配回答不同问题，不能互相替代。匹配后的显著差异仍需要条件可交换性和共同支持等假设才能解释为处理效应；不同列系数相减也不是 selection 份额。

2. 客户事前差异与可观察选择

2.1 进入前客户特征

首次合格换入要求此前连续三年非四大、从进入年起连续三年四大。204家公司的进入年份为1999—2022，193家此前没有四大观测，11家已有四大经历；因此“首次合格换入”不等于全部为首次聘用四大。对照为全观察期始终非四大的公司，按进入者批次组成比较相同日历年。事后三年留任要求也界定了这项比较的适用对象。

严格口径违规率在进入前第三年为1.96%，对照4.79%；进入前一年仍为1.96%，对照5.45%。亏损率和规模也显示事前差异。相反，进入者严格重述率由1.47%升至3.43%；公司内配对变化为+1.96个百分点，SE=1.20，95%CI=[−0.40,4.32]，p=0.103。中间口径变化+4.90（SE=2.67，CI=[−0.36,10.17]，p=0.068），宽口径+10.78（SE=3.39，CI=[4.10,17.47]，p=0.002）。这些是未经日历冲击调整的描述变化，不支持统一的“质量改善后进入”过程。

2.2 年度客户匹配：可观察调整后仍有质量差异

年度 PSM 比较当年四大与匹配非四大客户。两套候选样本均为70,677公司年度，包含4,782个四大观测；不同匹配对照分别为3,359（五项）和3,320（九项）。本隔离诊断按授权排除905个单边行业／年份观测及000506–2006、000892–2008两条非四大观测；未把这一排除推广到正式DTA或换所PSM-DID。

五项选择模型包含规模、杠杆、亏损、ROA、Z-score及缺失标记；九项另含杠杆变动、报告时滞、CFO和上市年限。行业、年份进入Logit，但不是精确匹配限制；使用有放回的1:1最近邻、无卡尺。五项未预警综合失败、重述和违规差异分别为−1.568、−0.669、−1.066个百分点；九项为−1.882、−1.192、−0.795，六项均在其AI稳健推断下达到1%显著水平。

这些结果支持可观察特征调整后的客户质量差异。AI稳健标准误没有按公司聚类；年度观测的公司内相关性仍需与其他公司聚类设计联合理解。五项并未增加四大处理数量，对照权重ESS为270.47，低于九项的371.30；九项仍有ROA/CFO尾部和方差不平衡。因此，匹配成功及显著性不意味着客户选择已消除，也不据此判定五项优于九项。

2.3 客户进入、留任与退出

相邻年度风险集中，非四大进入为342/61,459（0.56%），四大退出为283/4,396（6.44%）。MAO四大客户44/103次年退出（42.72%），非MAO客户239/4,293（5.57%）；44个事件涉及40家公司，其中一个后任事务所名称与ID缺失。没有次年观测不能记为退出。

沿用九项控制、缺失标记、公司和行业×年份固定效应、公司聚类，MAO对应四大客户次年退出概率高30.40个百分点（SE=7.35，CI=[15.96,44.84]，p<0.001）；非四大进入概率低0.249个百分点（SE=0.121，CI=[−0.485,−0.012]，p=0.039）。GC对应退出高20.62个百分点（p=0.042），进入差异不显著。这里识别的是意见与流动的条件关联，尚不能分辨审计师辞任和客户改聘。

对收到 MAO 后更换事务所的案例分析进一步佐证了双方的动态博弈：

  • 退市拉夏（2019→2020）： 公告提及“合理控制审计成本”，另一来源为收费分歧；尚无明确风险分歧证据；
  • 卓郎智能（2019→2020）： 集团控股股东主导更换；
  • 上海临港（2014→2015）： 重大资产重组导致审计机构重新洗牌；
  • 新城控股（2023→2024）： 业务发展与整体审计需求调整；
  • 鼎信通讯（2023→2024）： 连续服务超过十年，基于独立性与招投标程序轮换。

这些案例提供任期、费用、集团安排及重组等具体线索。深圳华强的“辞任”原因码与董事会改聘文字不一致；新城控股公告还明确不存在工作、费用或意见分歧，不能将这些记录统一归为四大主动辞任。

3. 审计结果水平差异

3.1 三种定义与三种分母

三种重述定义按既有规则保留：严格、中间（财务变更且非明确无盈余影响）和宽口径，三者为包含关系，不是互斥类型。失败按被更正或违规涉及的财年归属；意见为当年审计报告的MAO。

\[ P(Y=1),\qquad P(Y=1,\ MAO=0),\qquad P(Y=1\mid MAO=0). \]

回归中的未预警失败是第二项的联合指示变量，样本不按MAO=0筛掉。第三项才是在非MAO客户中的条件概率。严格综合失败的无条件率，四大、本土八大、Other分别为2.26%、6.47%、7.84%；联合率分别为1.99%、5.37%、5.94%。原始资料重建与正式面板逐键一致，但事件0只表示下载来源没有合格匹配记录，不能证明未发生事件。

旧重述公告库覆盖2001—2021、新库覆盖2017—2026；旧库盈余方向大量缺失，影响严格定义的早期覆盖。重述公告与被更正财年的中位间隔约1—2年，违规公告间隔中位3年。2021是旧库公告末年，不是事件发生年的无缝拼接点；末期较低率也可能包含以后才发现的问题。

3.2 共同样本下的嵌套比较

在同一71,241公司年度、5,626公司簇中，严格未预警综合失败的四大系数从无调整−3.66个百分点，变为公司及行业×年份FE下−1.18（SE=0.68，p=0.082），再加九项controls后−1.64（SE=0.69，p=0.017）。重述完整规格−0.42（SE=0.46，p=0.367），违规−1.51（SE=0.57，p=0.008）。总体质量梯度主要由违规及综合失败支持，不能把严格重述的不显著省略，也不能把列间系数变化解释成selection比例。

九项控制为规模、杠杆、亏损、ROA、Z-score、杠杆变动、年报披露时滞、CFO、上市年限及各自缺失标记；沿用年份中位数插补、全样本中位数回退。固定效应和controls调整的是本模型可观测差异，不自动解决时间变化的客户选择。

补充：原图、长期趋势与客户—事务所排序

中国审计市场的分层与长期趋势

将事务所分为四大（Big 4）、本土八大（Local 8）和其他事务所（Others）。按审计费用衡量的市场份额展现了市场结构的演化轨迹；而质量比较则以公司—年为基本观测单元。

四大客户在资产规模、审计费用及风险结构上明显不同。由此，四大与其他事务所的结果差异可能同时来自客户选择、审计服务以及事件被监管发现的过程。

1.1 市场质量的宏观趋势

为考察全市场审计质量的长期演进，模型采用三基线检验：

\[ Y^m_{it} = \alpha_i + \sum_{\tau \ne 2000} \eta^m_{\tau, s} \mathbf{1}\{\text{Year}=t\} + \mathbf{X}_{it}'\gamma_m + \varepsilon^m_{it}. \]

以 2000 年为基期，吸收公司固定效应并按公司聚类。三条基线分别对应：(1) 全部非平衡活跃公司；(2) 长期存续基线（2000—2024 年观测不少于 22 年）；(3) 本地五年连续基线（\([t-2, t+2]\) 窗口连续观测）。

审计失败趋势

综合失败率在各基线下均呈现 2008 年后上升、2016—2018 年达到阶段高点后逐步回落的非单调模式；长期存续样本的上升幅度更为明显。

财务重述与财务违规趋势提供了失败率的结构性拆解：单个指标的变化既反映审计质量，也受到监管披露政策与执法力度的影响。

截面事实的推论与疑问： 上述截面比较与 AKM 排序确立了四大客户更少发生审计失败的经验事实。但这究竟源于四大对企业财报生产的“直接治理改善（Treatment Effect）”，还是源于“优质客户与顶级事务所的主动匹配（Selection / Sorting）”？回答这一问题的关键在于检验企业在更换事务所前后的动态变化。

4. 换所及PSM-DID：同一客户的变化

4.1 三口径换入与换出

换入以始终非四大客户为对照，换出以始终四大客户为对照，保留既有稳定事件要求、九项controls、公司及行业×年份FE和公司聚类。当前自然样本换入严格综合失败−2.37个百分点（SE=1.09，p=0.030），严格重述−1.09（SE=0.77，p=0.158），违规−1.58（SE=0.85，p=0.062）。中间综合失败与重述分别−8.58和−8.08，宽口径分别−9.52和−8.96；换出未出现同样清楚的对称上升。

这比“换入没有用”的概括更具体：改进证据受测量定义和样本设计影响，需要结合动态路径、匹配比较和前期支持判断。

4.2 九项基线匹配DID及支持诊断

匹配在换入前一年进行，窗口为[−3,+2]，使用九项事前控制和缺失标记、行业与年份，不加入失败历史。回归吸收stack×公司、stack×行业×年份FE，保留九项结果controls，按原公司聚类。最终匹配加权回归包含1,194个堆叠行、113家处理和102家对照；公司可在多个批次出现，不能把堆叠N当作唯一公司年度。

中间口径综合失败−11.85个百分点（SE=3.78，CI=[−19.30,−4.40]，p=0.002）、重述−9.11（SE=3.11，CI=[−15.24,−2.97]，p=0.004）。17次逐一剔除cohort时，两者系数均为负、95%区间均不含零。严格综合失败−5.28（SE=2.56，CI=[−10.32,−0.25]，p=0.040），但剔除2017后变为−1.44、CI=[−4.26,1.39]。严格重述、违规和宽口径的非显著区间在下表保留，不能据此证明效应为零。

样本减少本身不否定匹配DID；需要核对最终比较和协变量。最终回归权重下ROA均值4.60%对3.28%，报告时滞93.64天对97.57天，SMD分别0.247、−0.211，仍有分布差异。36家原配对照退出的处理公司中32家所在cohort仍有对照，但部分cohort确实缺少直接前后比较；61个非零FE净化处理事件只是支持描述，没有数量有效性门槛。当前五项年度PSM不替代这套九项换所结果；五项是否同时用于34的选择与结果方程尚待确认。

4.3 动态路径与修正的SA

正向盈余惊喜与公告期股价反应

定义盈余惊喜为实际 EPS 超出分析师预测中位数的比例（\(Surprise > 10\%\)）。以公告前一交易日为基期，估计公告前后五个交易日的对数股价轨迹。

门槛规格描述正向消息组的公告期路径，以下完整保留原图与门槛扫描，和连续消息规格分别解释。

最新数据：门槛扫描与样本支持

将正向消息门槛从 5% 逐点提高至 30%，每次比较 \(Surprise>c\) 与 \(-c\leq Surprise\leq c\) 的事件。以下使用最新市场数据和原三组回归规格：2001—2024 财年、公告前 180 天预测、公司×财年、事件日及交易日期固定效应，公司×财年聚类，无额外控制变量。纵轴为四大或本土八大相对 Other 的正向消息反应增量，分别相对于公告前第 −1 个交易日；因变量为未乘以 100 的对数股价。

10% 点与原三组图的系数、标准误、置信区间及样本量完全一致：四大−Other 在第 0 天为 0.003837（标准误 0.001331，\(p=0.004\)），第 +1 天为 0.003671（标准误 0.001790，\(p=0.040\)），第 +5 天为 0.003066（标准误 0.002672，\(p=0.251\)）。完整扫描中，第 0 天的四大增量在 5%—18% 门槛达到 5% 显著性，第 +1 天在 10%—15% 达到；第 +2、+5 天均未达到 5% 显著性。

曲线右端为何下降？ 提高门槛同时改变了正向组和中性组，因而每个点对应不同的组间比较。四大正向事件从 10% 门槛的 817 个降至 30% 的 334 个，正向组占该组实际正向＋中性样本的比例从 31.7% 降至 11.3%；高门槛仍有正向事件，不能解释为“没有 treatment”。正向支持减少与估计精度下降相伴，但并不机械地使系数趋近于零。

右端下降也不是只有置信区间变宽：将门槛从 15% 提高到 18%，第 +1 天四大−Other 的点估计从 0.004331 降至 0.002457，而标准误只从 0.002041 升至 0.002164。在同一 pooled 模型中拆开看，四大组内正向消息反应从 0.004949 降至 0.003692，Other 从 0.000618 升至 0.001235，两者共同缩小了差值。同期正向组减少，原来属于正向组的中等正向消息进入中性组，且中性组也纳入更负的消息；组别构成和两组的反应差异随之改变。这些变化是需要区分的解释，目前尚未通过固定样本或逐项分解确定哪个因素主导下降。

理论上为什么可以下降？ 门槛扫描改变比较组，不是沿着同一公司的消息反应函数移动。若四大的反应优势集中在中等消息，而大消息下两组反应逐渐趋同，提高门槛会更多保留组间差异较小的尾部消息。允许各组有自身中性路径时，将已有正向反应的中等消息纳入中性组也可能缩小正向对中性的差值；但原模型省略了组别×事件日项，不能直接用两组各自“正向减中性”的解释替代其系数。

一个简化反例可以说明这点，但不代表本数据的拟合：设两组 surprise 均匀分布于 0 至 1，四大反应为 \(r_4(s)=A\min(s/0.10,1)\)，Other 为 \(r_O(s)=A\min(s/0.30,1)\)，\(A>0\)。四大在中等消息时反应更高，但两组最终达到相同平台。忽略日期固定效应的简化 pooled 模型中，共同中性基准在组间相减时抵消；当 \(0.10\leq c\leq0.30\) 时，正向组平均反应差为 \(A(0.30-c)^2/[0.60(1-c)]\)，随门槛下降至零。这里没有抽样误差，正向样本也没有消失，下降来自尾部消息的反应差异。相反，在共同分布、线性反应及固定四大斜率优势的简单设定下，不能仅靠提高门槛解释下降。该例只说明下降在理论上可能，实际模型还包括日期固定效应；当前结果仍需区分反应非线性、样本构成和 EPS 比率分母造成的大 surprise，尚未确认是哪种机制。

解释还受到原规格及前期路径限制：原 pooled 模型未单独加入事务所组别×事件日项；四大−Other 的公告前 −5 至 −2 日联合检验，在 9% 及 11%—27% 门槛达到 5% 显著性，10% 门槛的 \(p=0.063\)。因此，这张图支持原规格下的公告初期条件差异，尚不能单独将其归因为纯信息认证，也不能用不同门槛下显著性变化证明效应消失。

6. 当前解释与待完成

现有基础设计得到三项具体认识。第一，四大进入者已有可观察的客户差异，年度匹配后失败差异仍为负；但剩余差异不等于审计师私有信息。第二，中间口径换所及九项匹配DID给出较稳定的负向结果，严格口径和部分动态结果更敏感；审计处理效应不能被统一否定，也尚不能推广到所有客户和质量维度。第三，部分连续市场规格支持公告初期斜率差及固定消息水平差，门槛与筛选结果则显示规格和参照组的重要性。

这些结果与审计服务、客户选择和信息可信度同时有关，目前没有完成三者的数值分解。尤其是研究者未测到的特征未必对投资者未知；进入前第1财年的192份已知审计报告均在进入财年出具，尚未对齐实际聘任与公开信息时点。不能由换所不显著推导“全部优势来自selection”，也不能由价格反应与收费溢价推导“收费本质就是认证费”。

下一步集中于基础比较中已明确的剩余工作：确认34五项controls用于选择方程还是也精简结果方程；保留九项完整结果作为对照；核对共同支持和残余尾部不平衡的解释；在同一估计对象内检验消息与客户可比性。未来盈利／现金流兑现以及人员、分所覆盖放在补充研究位置，不作为当前机制已经成立的证据，也不在本次新增估计。
